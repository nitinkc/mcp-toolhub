# 💬 Chat Prompt Recipes

> Copy-paste these prompts directly into Claude (or any MCP-compatible client) to test and explore every feature of MCP ToolHub.

---

## How to use these recipes

1. Make sure MCP ToolHub is connected in Claude Desktop (green dot next to the server name)
2. Copy any prompt block below
3. Paste it into Claude's chat
4. Watch Claude automatically select and call the right MCP tools!

## Quick-Fire Sampler

Want a quick tour? Try these one-liners in order:

```
1. Echo "MCP ToolHub is alive!" back to me
2. What is 12 factorial?
3. What's the current price of Ethereum?
4. Add a note: "I started learning MCP today"
5. Read all my notes
6. Show me the inventory overview
7. Take a screenshot and describe what's on my screen
8. Save this to memory: "MCP Tools return data, Prompts shape responses, Resources expose read-only data"
9. Search my memories for "MCP"
10. Use the analyze_topic prompt for "Model Context Protocol"
```
